# Diagram inventory

The current PINN report uses seven scientific graphs and **no separate diagrams**.
Every referenced graph is supplied in EPS format in `report/graphs/`. Matching vector
PDF files support PDF-engine compilation of the same graph content.

There are no missing external diagram files. If the final group report adds a diagram,
place its original editable/source file and any rendering used by LaTeX in this folder,
update the report paths and rebuild the submission ZIP.
